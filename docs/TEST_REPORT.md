## 图形界面验证方式

当前容器中的 Chromium 有管理策略，阻止所有 URL 导航，包括 localhost。本次**没有修改浏览器管理策略**。实际 UI 资源（HTML 容器、CSS、JavaScript）在内存中装载到 Chromium；测试通过一个只允许 `/api/*` 的 Python 桥连接本机真实 Node HTTP 服务。

因此本次 UI 检查验证了实际界面代码、用户操作、表单、状态和本机 API 的配合，但**不是正常浏览器导航 / Electron 窗口网络的端到端验收**。浏览器测试使用轮询恢复状态；SSE 的套接字消息交付由独立 Node HTTP 测试实际验证。

通过的 15 组图形检查包括：初始工作台、添加/保存/切换供应商、项目目录桥接与添加、紫色 Ultra、明确标注的加速占位、七个截图模型预设菜单、项目菜单/置顶、从本机测试额度接口读取 27%、MCP 信任勾选与默认禁用、技能保存、浅/深色切换、审批与流式消息展示、代码复制控件呈现、会话重命名/归档、页面切换后供应商状态保留。

系统剪贴板在受限浏览器中不可用，测试仅确认复制控件存在，不宣称已验证系统剪贴板。新加入的 Electron 受限剪贴板 IPC 需要 Windows 验收。
